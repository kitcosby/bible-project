Design notes

  • Interlinear columns follow Hebrew word order (RTL). Each column stacks: Hebrew word → Variant dropdown (every word_variants row: unpointed, letters, convention, variant_kind) → Translation dropdown (KJV · Young's Literal · Computed · Custom). Blank variant = corpus default.
  • English sentence renders left-to-right in English syntax from the chosen translations. Words the translator must add for English grammar (articles, etc., with no Hebrew source word) render in italics, following the KJV convention of marking supplied words.
  • Selecting + Add custom rendering… would prompt login (if anonymous) then open a text box; the entry is saved per user per word (see schema_custom.sql).
  • Open design question (logged as bible-project#5): should choosing a variant filter which translations are offered, or stay independent?
