## Revelation 7:3 verb-form variant review (2026-11-07)

Robinson group 66:9 records A=σφραγίζωμεν (present active subjunctive, 1pl) and B=σφραγίσωμεν (aorist active subjunctive, 1pl). YLT “till we may seal” does not discriminate between these forms. Edition comparison found Stephanus 1550 and Beza 1598 with A, but Elzevir 1624, Scrivener 1894, Nestle 1904, Westcott–Hort, and SBL GNT with B. Young's preface names the generally recognized Received Text but not a specific edition. Keep the YLT profile unresolved and the rest of Revelation 7:3 unmaterialized. The separate ἄχρι / ἄχρις οὗ connective variation must not be conflated with group 66:9. See [the Revelation 7:3 verb-variant review](REVELATION_7_3_VERB_VARIANT_REVIEW_20261107.md).

## Hebrew vowel-only variant policy (2026-11-07)

A source-code audit is now documented in [HEBREW_VOWEL_VARIANT_AUDIT_20261107.md](HEBREW_VOWEL_VARIANT_AUDIT_20261107.md). Findings: OSHB pointed text is preserved, but its unpointed export removes all non-letter marks indiscriminately; the current spelling builder does not create niqqud-only links; qere is already a separate textual apparatus; and word_variants has no cross-occurrence group key. The existing root_vowel tier already groups distinct pointed strings beneath each (root, form), but does not classify vowel-only differences and is scoped by current root/form assignments. The read-only inventory must cross-reference those IDs before deciding whether a dedicated form-group/member relation is needed. Strict comparison should remove only vowel-point code points and retain consonants, matres lectionis, final forms, dagesh, shin/sin dots, meteg, cantillation, and separators. This is a code review only; corpus-wide candidate counts remain unknown and no database or parser changes were made.



Hebrew forms with identical consonantal spelling that differ only in vowel points / niqqud must be linked as branches of a shared variant group. Preserve exact vocalized source strings and provenance; do not collapse the forms into one token or lexical entry, because vocalization can change morphology, pronunciation, and sense. Use Hebrew-aware Unicode normalization and niqqud-specific comparison, not indiscriminate removal of combining marks. Differences involving consonant letters or matres lectionis, cantillation, qere/ketiv, or uncertain normalization require separate review rather than automatic vowel-only grouping.
