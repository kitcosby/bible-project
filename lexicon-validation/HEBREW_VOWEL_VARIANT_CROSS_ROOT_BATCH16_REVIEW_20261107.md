## 4. `את־דּבר֣י`

## 15. `ל֤ך`

לֵךְ is the imperative “go!” (H3212); לָךְ is “to you” (2fs suffix; Strong’s is null in the source member). This is an orthographic collision between verb and preposition, not a semantic variant.

## Disposition and limitations

Most cases are inflectional forms within the same lexical family: construct state versus pronominal suffix, number, object suffix, or verbal conjugation. The לֵךְ / לָךְ pair is a clear unrelated-lexeme collision; the prepositional member has no Strong’s value in the supplied source data, and that null is preserved. These findings record member-level inspection only; all links remain orthographic candidates.
